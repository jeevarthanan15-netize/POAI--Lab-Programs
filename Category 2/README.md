# AI Environment Types using Python

This repository contains Python implementations of the **12 AI Environment Types**. Each program demonstrates a different environment using a simple real-world scenario.

## Environments Implemented

| No. | Environment | Project |
|:---:|-------------|---------|
| 01 | Fully Observable | Smart Factory Machine Inspector |
| 02 | Partially Observable | Forest Fire Detection Drone |
| 03 | Known | Smart Traffic Signal Controller |
| 04 | Unknown | Mars Exploration Rover |
| 05 | Static | Library Book Organizer |
| 06 | Dynamic | Ambulance Route Assistant |
| 07 | Discrete | Smart Parking Slot Finder |
| 08 | Continuous | Smart Greenhouse Climate Controller |
| 09 | Deterministic | ATM Cash Dispensing Agent |
| 10 | Stochastic | Weather-Based Travel Advisor |
| 11 | Episodic | Automatic Face Mask Checker |
| 12 | Sequential | Warehouse Delivery Robot |
