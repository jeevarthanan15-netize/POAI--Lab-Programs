# AI-MODELS

This repository contains implementations of different Artificial Intelligence (AI) agent models using Python. Each project demonstrates the working of a different intelligent agent through a simple real-world example.

## Implemented AI Agent Models

### 1. Simple Reflex Agent
**Project:** Smart Library Silence Monitor

- Monitors the current noise level.
- Displays a warning if the noise exceeds the threshold.
- Makes decisions based only on the current input.

### 2. Model-Based Agent
**Project:** Smart Museum Artifact Protection System

- Monitors the distance between visitors and museum artifacts.
- Remembers whether a warning has already been given.
- Uses internal memory to make better decisions.

### 3. Goal-Based Agent
**Project:** Flood Escape Agent

- Finds a safe path to the relief camp.
- Uses Breadth-First Search (BFS).
- Avoids flooded roads while planning the route.

### 4. Utility-Based Agent
**Project:** Wildlife Safari Guide Agent

- Evaluates multiple safari routes.
- Calculates a utility score for each route.
- Recommends the best route based on overall utility.
